# Titre du document

Document modèle appliquant la DA BDDev. Markdown **standard** : il s'exporte en PDF
(thème sombre, voir `theme.css`) **et** s'importe proprement dans Google Docs.

> `[ o_o ]` La mascotte Cody ne passe pas en PDF/Docs comme composant : on la rend
> en texte, en Geist Mono. Exemple : `[ ^‿^ ]`.

---

###### // SECTION 01

## Première section

Texte courant. Les mots forts se mettent en **gras**, et un terme du langage métier
en *accent* (rendu rose dans le PDF).

- Point un, avec une puce rose.
- Point deux.
- Point trois.

### Sous-partie

Un bloc de code en Geist Mono :

```ts
const cody = { mood: "code", brackets: "angle" }; // [ </> ]
```
